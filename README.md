# 社交网络图谱分析及智能推荐系统

## 项目概述

本项目为数据结构课程设计作品，基于自主实现的无向加权图、哈希表、小顶堆等数据结构，开发社交网络图谱分析及智能推荐系统。系统支持用户关系建模、多度人脉查询、社交距离计算、兴趣推荐、黑名单过滤、交互式网络图可视化等核心功能，旨在掌握数据结构底层原理与系统开发全流程。

## 运行步骤

### 源码运行

1. 下载源代码包并解压，用 PyCharm 打开项目目录。
2. 安装依赖库：
   ```bash
   pip install -r requirements.txt
   ```
   或单独安装：
   ```bash
   pip install pyvis matplotlib pytest pytest-cov
   ```
3. 定位到 `src/app.py`，右键运行或执行：
   ```bash
   python src/app.py
   ```
4. 程序启动后，可通过 **文件 → 加载默认数据** 菜单加载 `data/` 目录下的测试数据，或手动选择其他 CSV/TXT 文件。

### 打包为可执行文件（可选）

```bash

pip install pyinstaller

# 打包（Windows）—— 无图标版本（推荐，避免图标文件缺失报错）
pyinstaller -F -w src/app.py -n "社交网络分析系统"

# 若需添加自定义图标，请先在 docs/ 目录下准备 icon.ico 文件，再执行：
pyinstaller -F -w -i docs/icon.ico src/app.py -n "社交网络分析系统"

# 打包后，需将 data 目录复制到 dist 文件夹同级路径
```

> **提示**：打包生成的 `.exe` 文件位于 `dist/` 目录下。运行前请确保 `data/` 文件夹与 `.exe` 处于同一目录，否则程序无法加载数据。

## 数据格式说明

系统支持从 CSV/TXT 文件加载数据，自定义格式如下：

### 用户信息（users.csv）

```csv
用户ID,姓名,兴趣标签
1,张三,编程;篮球;摄影
2,李四,阅读;音乐;旅行
```

- 表头必须包含 `用户ID`、`姓名`、`兴趣标签`。
- 兴趣标签使用中文分号 `；` 或英文分号 `;` 分隔（推荐 `；`），代码会自动解析。
- 文件编码推荐 UTF-8，自动适配 GBK/GB2312。

### 好友关系（relationships.txt）

```txt
用户ID1,用户ID2,权重
1,2,5
1,3,8
```

- 每行至少包含两个用户ID，用逗号或空格分隔（推荐逗号）。
- 第三列为可选权重，默认值为 1。
- 支持 `#` 开头的注释行，空行自动跳过。
- 文件编码推荐 UTF-8，自动适配 GBK/GB2312。

## 功能说明

### 基础功能（全部实现）

| 序号 | 功能模块 | 说明 |
|------|----------|------|
| 1 | 图结构建模 | 自研无向加权图邻接表，支持用户/好友增删改查 |
| 2 | 数据持久化 | 加载 CSV 用户数据与 TXT 关系数据，兼容多种编码 |
| 3 | 一度人脉查询 | 查询直接好友，支持按 ID/亲密度/共同兴趣排序 |
| 4 | 二度人脉发现 | 基于 BFS 算法，展示好友的好友及连通路径，自动排除自身与直接好友 |
| 5 | 社交距离计算 | 支持无权图（BFS）与加权图（Dijkstra）两种模式，返回最短路径与距离 |
| 6 | 用户信息管理 | 自研哈希表缓存用户信息，O(1) 查询 |
| 7 | GUI 界面 | Tkinter 桌面应用，包含数据加载、查询、管理、可视化全功能 |

### 扩展功能（已实现）

- **扩展功能 A（多度人脉）**：支持 3 度及以上自定义度数查询，BFS 分层扩展。
- **扩展功能 C（兴趣推荐）**：基于兴趣倒排索引，推荐 Top-K 潜在好友，展示共同兴趣列表与推荐理由。
- **扩展功能 E（网络可视化）**：使用 PyVis 生成交互式 HTML 网络图，节点颜色按人脉层级区分（红/蓝/绿/灰），支持黑名单过滤与子图聚焦。
- **附加功能**：
  - 黑名单管理（增/删/查/清），所有查询与可视化自动过滤黑名单用户。
  - 社群划分（连通分量分析）。
  - 度中心性排行（识别社交核心用户）。
  - 数据导出（标准邻接表、纯文本表格）。
  - 大数据性能测试工具（可生成 1000+ 用户、5000+ 关系）。

## 注意事项

- 核心数据结构（邻接表、哈希表、小顶堆）均为**自主实现**，未调用任何第三方图库（如 NetworkX）。
- 运行前请确保 `data` 目录下存在测试数据文件，或通过菜单手动加载。
- 若使用 PyVis 可视化，需先安装 `pyvis` 库：`pip install pyvis`。
- 程序异常可查看控制台输出或 GUI 操作日志（右侧“操作日志”区域）。
- 打包后可执行文件需将 `data` 目录复制到同路径下，否则无法加载数据。
- `.gitignore` 文件建议保留，用于屏蔽 `__pycache__/`、`venv/` 等自动生成文件，保持仓库整洁。
